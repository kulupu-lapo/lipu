### poki Lapo
**poki Lapo** é uma biblioteca e corpus monolíngue de toki pona. Nossa visão é o expandir para que inclua todos os tipos de mídia em toki pona, incluindo livros, poesias, músicas, quadrinhos, posts e mais. Arquivos são transcritos por voluntários em um formato Markdown com metadados e armazenados em um repositório do Github.  
  
Para fazer commit de trabalhos para o poki Lapo, você pode clonar [o repositório](https://github.com/kulupu-lapo/poki) em `kulupu-lapo/poki` no Github. Se você não tem experiência com o Git ou isso parece um compromisso grande demais, você também pode enviar entradas únicas direto desse site usando o botão [Adicionar](./add).  
  
Você também pode entrar no servidor do **ma pona pi toki pona** no Discord para falar com os mantenedores na nossa postagem no [`#tomo-mute`](https://discord.com/channels/301377942062366741/1252224729977327647).

### lipu Lapo
**lipu Lapo** (esse site) é um front-end do [poki Lapo](#poki-lapo). Ele está hospedado no Github pages e foi feito com o gerador de sites estáticos Astro, que renderiza entradas e coleções dos arquivos Markdown armazenados no poki Lapo.
